# AI Empowerment Observatory

A source-linked weekly view of what AI news means for people: who is gaining,
who is losing ground, where the picture is mixed, who may be left behind, and
what is still not clear.

Start with `FULL-REPOSITORY-HANDOFF.md`. It explains how to install this
complete repository, verify the public build, apply the multilingual policy,
and run whole-week or repeatable relationship quality control.
